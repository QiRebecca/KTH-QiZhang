# Artifact Manifest

The authoritative machine-readable manifest is
[`artifacts/manifest.json`](../artifacts/manifest.json). It is generated by
[`scripts/write_manifest.py`](../scripts/write_manifest.py) and records the
Qwen target model, layer convention, split sizes, seed, runtime note, and
SHA-256 hashes for reproducibility-critical artifacts.

All files listed below are full-run Qwen artifacts unless explicitly marked
otherwise. Smoke outputs are kept outside `artifacts/`, under `artifacts_smoke/`,
`data_smoke/`, `figures_smoke/`, or `tests/fixtures/smoke/`.

## Main Run Identity

| field | value |
|---|---|
| run type | `full_qwen_main` |
| model | `Qwen/Qwen2.5-Coder-1.5B-Instruct` |
| reported layer | `target_layer_label = 18` |
| block index | `target_block_index_zero_based = 17` |
| hidden-state index | `hidden_states_index = 18` |
| d_model | `1536` |
| seed | `17` |
| final AV eval | activation vector plus fixed prompt only |
| observed GPU runtime | about 8h12m on one A100 40GB |

## Figures

Figures live in [`figures/`](../figures/) and can be rebuilt from existing
artifacts without GPU:

```bash
python3 scripts/reproduce_figures.py --artifacts artifacts --figures figures
```

The four required figures are `architecture.png`, `main_fve_bar.png`,
`reconstruction_distribution.png`, and `token_role_breakdown.png`.

## Large Files and LFS

The largest required artifact in the current repository state is
`artifacts/activations.npz`, about 90 MB. No file exceeds 100 MB, so Git LFS is
not required for the current artifact set. Before pushing, run:

```bash
find . -path ./.git -prune -o -type f -size +50M -print
find . -path ./.git -prune -o -type f -size +100M -print
python3 scripts/check_submission_ready.py
```

If any future artifact exceeds the hosting limit, track the large `.npz` files
with Git LFS and verify that the working tree contains real binary files, not
unpulled LFS pointer files.
